# Agent Demo

该素材展示 AI Accounting Copilot V2.0 一次精简的成功运行过程，适合用于 GitHub README 项目演示。

展示内容包括：

- **LLM Router**：根据问题和当前状态选择下一项财务工具。
- **Agent Loop**：控制工具执行顺序、完成状态和最终响应流程。
- **Financial Tools**：依次执行指标计算、异常检测、趋势分析和财务洞察。
- **AI Response**：综合 Agent Context 中的分析结果，生成最终财务诊断。

`agent_demo_output.txt` 是便于在 Windows Terminal 或 VS Code Terminal 中打开的精简文本；`agent_demo_output.png` 是由该文本生成的静态终端风格展示图。展示数据来自项目示例运行结果，异常交易仅保留汇总结论，未展开全部明细。
