# AI Accounting Copilot v2.2

## Highlights

- Streamlit Dashboard
- Interactive financial analysis
- Agent workflow visualization
- KPI cards, expense trend chart, and abnormal transaction table
- Markdown report download
- Local and Streamlit Cloud API key configuration

## Breaking Changes

None.

## Architecture

The Agent core remains unchanged. Version v2.2 adds a product-oriented Web presentation layer around the existing LLM Router, Agent Loop, Tool Executor, Context, and Financial Tools.

## Run

```bash
streamlit run web_app.py
```
